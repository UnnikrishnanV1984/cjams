Person Search Instructions
  • This function is used to search for an existing Person in Local or the State database.
  • User's can perform either Person Name (entering one or more of the following values: Last Name, First Name, Gender, DOB) or Person Identifier (DCN and/or SSN) Search.
  • The State Search is enabled only after performing the Local Search.
  • The Add Person button will be enabled only after performing a search of State.
  • The minimum required fields for performing a Person Name Search is either Last Name (min 2 characters) and First Name (min 1 character) and Year of Birth.
  • The minimum required fields for performing a Person Identifier Search are either DCN or SSN.
  • The required fields to register a Person with a DCN include: Last Name, First Name, DOB, Gender, Ethnicity, Race and Primary Language. The user must have the proper security role to assign and/or update DCN pedigree information; a DCN cannot be assigned until after both a CC Search and Common Search have been performed.
  • The required fields to register a Person without DCN are: Last Name and First Name.
  • Clicking on the Reset Search button, clear the search criteria and the search results.
